# Click Clack documentation

Customer-facing docs for checking Click Clack provenance receipts. Live site: [clickclack.mintlify.site](https://clickclack.mintlify.site).

Writers export a signed history. Publishers, editors, and platforms check it with `click-clack-verify` — no Click Clack account required.

```bash
npm i -g mint
mint dev
```

Install the independent checker with `npm install --global @click-clack/provenance-verifier`.
